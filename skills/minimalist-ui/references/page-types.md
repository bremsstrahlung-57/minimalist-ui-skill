# Page types and composition

Use page type as a starting point, not a template. Choose the dials, width, density, and visual motif from the real task and content. Each view needs one focal point and one primary action; some reading views have no action beyond navigation.

| Page type | Starting TEXTURE / DENSITY / MOTION | Composition choices | Default restraint |
| --- | --- | --- | --- |
| Documentation, help, article, blog | 2 / 4 / 1 | Comfortable reading measure, useful hierarchy, local contents navigation when needed, clear code and media | No ambient canvas; no frames around every paragraph |
| Dashboard, operations, analytics | 2 / 8 / 1 | Persistent orientation, filters near results, readable table/data region, explicit empty/loading/error states | No canvas or glow over data |
| Forms, checkout, settings | 3 / 5 / 1 | Keep related choices, validation, price/impact, and next action together | Quiet borders, no motion beyond feedback |
| Store, catalog, booking | 4 / 5 / 2 | Real imagery, comparable item scan patterns, visible prices/options, clear transaction states | No fictional proof or terminal jokes in purchase steps |
| Landing or product page | 7 / 4 / 4 | State the real offer and audience quickly; make evidence, details, and primary action easy to find | No invented logo walls, testimonials, or stats |
| Directory or community | 4 / 6 / 2 | Browse/search only when useful; clear item identity, filters, and contribution route | No fake activity or decorative counters |
| Personal site | 7 / 4 / 4 | Let the person's actual work, interests, or writing determine the sections | No default project/books/blog/GitHub section set |
| Tool or editor | 3 / 7 / 2 | Keep the working surface dominant; group related controls and provide direct status | Ambient motion off around precision work |

Adjust values to user preference. If multiple contexts exist, set values per screen instead of averaging into one style. Higher density means efficient hierarchy and scannable grouping, not smaller essential type. Higher texture means more distinctive strokes, glyphs, and surfaces, not a pile of effects.
